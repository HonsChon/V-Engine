Welcome! This is a Vulkan-based game engine learning project.  
  
=== Quick Start ===  
  
1. Read project status document first:  
   .ai/PROJECT_STATUS.md  
  
2. Full project README:  
   README.md

4. Core C++ files:  
   - src/renderer/VulkanRenderer.cpp  
   - src/passes/SSRPass.cpp  
   - src/passes/WaterPass.cpp
